## Формат граматики

```
S → AbCa | ABB | aSB
A → Aa | ε
```

- нетермінал починається з великої літери, термінал з малої;
- ε записується як `ε`, `eps` або `epsilon`;
- `->` можна замість `→`, правила розділяються рядками, комами чи `;`;
- символи без пробілів читаються по одному, штрих `′` або `'` належить попередньому символу (`B′`);
- символи з пробілами можуть бути довшими (`E → E plus T`), але лівий бік правила завжди один символ;
- `#` починає коментар.

| `formal/equations.py` | модель рівнянь над мовами, розбір нотації, наближення, пояснення кроків, порівняння, родина `{p xⁿ m yⁿ s}` |

## Derivation Explorer

`sipl derive <граматика> <слово>` будує всі дерева виводу слова висотою не більше `--depth` (за замовчуванням 10) і не більше `--limit` штук (за замовчуванням 10). Для кожного дерева друкується лівостороннє та правостороннє виведення з правилом на кожному кроці. Якщо дерев кілька, граматика неоднозначна для цього слова. Порожнє слово записується як `ε`. Формати виводу: `text`, `json`, `dot` (для Graphviz).

## Системи рівнянь (FORM-02)

Нотація як у практичній роботі 5: `X = t₁ ∪ t₂`, де доданок — конкатенація `{слово}` та змінних; `{ε}` — порожнє слово, `∅` — порожня мова. Роздільники рівнянь: рядок, кома або `;`; замість `∪` можна `|`.

```
S = {aaa}A
A = {dd}A{c} ∪ {ε}
```

| Команда | Що робить |
|---|---|
| `sipl eq convert <файл>` | граматика ⇄ система рівнянь (`X → α \| β` ↔ `X = α ∪ β`); тип файлу визначається за наявністю `→` |
| `sipl eq solve <файл>` | наближення X₀ = ∅, X₁ = F(X₀), … (одночасно для всіх змінних), нерухома точка, розв'язок R(E) |
| `sipl eq solve … --compare G.txt` | порівняння R(E) з L(G) для кожної змінної; різниця слів у разі розбіжності |
| `sipl eq solve … --entry-levels` | з якого наближення з'являється кожне слово |
| `sipl eq solve … --format json` | усі рівні, розв'язок, `stable_at`, порівняння |
| `sipl eq build --prefix p --left x --middle m --right y --suffix s` | G і E для родини `{p xⁿ m yⁿ s}`; перевірка L(G) = R(E) = L прямим перелічуванням |

Коди завершення: `0` успіх, `1` помилка синтаксису/аргументів, `2` файл не прочитано, `3` R(E) ≠ L(G).

**Чому обрізання за довжиною коректне.** Конкатенація не вкорочує слів, тому слова довжини ≤ L у Xₖ₊₁ залежать лише від слів довжини ≤ L у Xₖ. Отже ⋃ₖ Xₖ ∩ Σ≤ᴸ обчислюється точно, а «нерухома точка досягнута» означає: усі слова довжини ≤ L вже знайдено.

**Межі.** Для нескінченних мов результат — лише слова до заданої довжини; доведення R(E) = L для всіх n лишається за людиною (індукція за k, як у ПР5). У рівняннях символи односимвольні (з можливим штрихом). Порівняння з граматикою використовує `language_up_to`, яка теж є ітерацією до нерухомої точки; повністю незалежний еталон дає лише `eq build` (пряме перелічування мови) і ручні формули Aₖ у тестах.

## Pumping Lemma Explorer (FORM-03)

Лема (формулювання з ПР6): якщо L — КВ-мова, то існує k, таке що для кожного `t ∈ L`, `|t| ≥ k`, є розклад `t = u t₁ x t₂ v` з `|t₁t₂| ≥ 1`, `|t₁xt₂| ≤ k` та `u t₁ⁱ x t₂ⁱ v ∈ L` для всіх `i ≥ 0`.

`sipl pump` перебирає **усі** розклади слова для заданого `k`, показує, які накачуються, а для решти — перше `i`, при якому накачане слово виходить з мови. Мову задають граматикою (`--grammar`, перевірка CYK), готовою назвою (`--lang anbn|anbncn|ww|pr6`) або предикатом Python (`--pred "w.count('a')==w.count('b')"`). Слово — буквально (`--word`) або виразом від `k` (`--word-expr`), тоді можна задати кілька `-k`. `--split "u|t1|x|t2|v"` перевіряє один розклад; `--max-i` обмежує перевірені `i`; `--format json` для інтеграцій.

**Це асистент, а не розв'язувач.** Одне слово, одне `k` і скінченне `i` нічого не доводять. Доведення, що мова не КВ, потребує слова як функції від довільного `k` та аргументу для всіх розкладів (як у ПР6, п. 4). Інструмент лише ілюструє: якщо для `k = 1…5` жоден розклад не накачується, це сильна підказка, але не доведення. `--pred` і `--word-expr` виконують вираз Python локально (без доступу до `builtins`, окрім невеликого набору), тож не запускайте чужі вирази.

## Тести

```
pytest
```

Перевіряються приклади з практичної роботи 4 і 5 (наближення Aₖ, Sₖ з формулами з доведення), структура результату та збереження мови на 150 випадкових граматиках.

## Обмеження

- Граматика має бути контекстно-вільною.
- Еквівалентність у тестах перевіряється до обмеженої довжини слів.
- Дерева виводу шукаються лише в межах заданої висоти, тому відсутність дерев не доводить, що слова немає в мові, а лише що його не виведено за цю висоту. Для граматик з одиничними циклами (`S → S`) кількість дерев також обмежується висотою.
